# 全 iPAS 考科與官方題源擴充

## 使用者目標

補足 AIoT 官方指引與適用歷屆試題，並把 iPAS 有的考科全都納入網站。以官方目前公開的鑑定清單、各級別考科、學習資源與試卷為準；舊制項目保留原制別。不是只新增名稱卡片：每個考科要有可用官方準備資源，有完整且可核對答案的公開題卷則逐批轉入互動練習。

## 實作方向

保留既有四個學習區和穩定題目 ID、學習紀錄。新增共用考科目錄以資料驅動呈現所有鑑定、級別、筆試/術科與資源；避免複製十多套應用。先完整接入 AIoT 官方指引及舊制 IoT 題庫，再用同一來源記錄與審核方式擴充其他鑑定。

## 主要風險與應對

1. 官網搬遷造成舊連結失效：保留原出處，優先找新官方URL與可驗證的原卷副本，不用第三方解析充當官方資料。
2. PDF 表格、圖片和跨頁題組遺失：核對原頁，缺必需資料的題目排除互動作答。
3. 官方指引自身疑義：原答案與網站查核結論分欄保留。
4. 誤標題源或跨制別：明確 sourceKind、原考科、年度與出處。
5. 舊進度相容：不改既有题目ID與資料namespace，不用新題取代原題身份。

本文件追蹤完整目標；分批完成不等於整體完成。
