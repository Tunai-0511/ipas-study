## 檢查紀錄

- 建置程式核對 28 科完整集合、每科 10 題、280 個唯一 ID、每題 4 個不重複選項、答案映射、HTTPS 來源與所有圖片路徑。
- 51 組獨立數值斷言涵蓋色差／對比、折現、權利金、感測與 ADC、流量、統計與分類指標、像素記憶體和移動向量。
- 每張 SVG 經 XML 解析；文字依字寬自動換行並檢查容器寬度。圖的替代文字含完整列值與必要假設。
- 84 張 SVG 全數以 sharp 點陣渲染，並在 7 張聯絡表逐圖目視核對；文字未被裁切。修正英數識別字被截斷換行、三欄寬度及非序列資料誤畫成流程箭頭的問題，再次渲染並逐圖檢視。
- 另實際執行 Python 缺漏篩選，以及 SQLite 的 INNER JOIN、LEFT JOIN、DESC 排序，結果與題目答案一致。答案 A/B/C/D 各 70 題；題幹無完全重複。
