| 範圍 | 本次資料 |

| 新增自編合計 | 460 題、129 張 SVG；每題附圖，情境圖可供數題共用 |
| 全站來源題目 ID | 8,708 個，按 `originalId || id` 計數 |
| 按鑑定分片後的練習項目 | 9,751 筆，其中 7,350 筆附圖片 |

8,708 是來源 ID 去重數，**不是文字、概念或語意去重後的不同題數**。同一來源題可能映射至新舊考科，所以分片項目數較多；既有章節題亦保留，不能將「每科都有圖片題」寫成「全站每道題均有圖片」。27 組共用情境與原卷的 27 題官方全給分題是不同統計；全給分題不計入上述 6,852 題可判分刷題。

官方、自編、舊制及術科準備逐題區分。自編題不稱官方考題；術科圖解判讀不取代現場操作。練習正確率不代表正式配分或證照通過資格。
