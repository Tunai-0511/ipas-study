# iPAS 鑑定與考科收錄範圍

查核日：2026-10-01（民國 115 年）。來源入口：[經濟部 iPAS 官方首頁](https://ipd.nat.gov.tw/ipas/)。

## 現行範圍與完成標準

- 官方首頁 17 項現行鑑定全部收錄，涵蓋 30 個級別、75 個考科；包括初級、中級、高級、選考與術科，不把同一鑑定不同級別算成不同鑑定。
- 已核對 16 個新版鑑定的 `exam-info`、`learning-resources`、`downloads` 共 48 頁，以及外連品牌企劃師網站的簡章與學習資源。16 份新版年度簡章均下載並抽取考試表；品牌簡章另由官方 PDF 內容核對。
- 現行目錄含 158 筆資源，其中 61 筆正式歷屆／當屆公告試題資源（含食品所題庫入口）。其餘是樣題、學習指引、簡章／抵免辦法、官方推薦課程。資源連結不等於已完成互動題庫。
- 現行鑑定名單與考科已完整對照查核時的官方首頁及年度簡章；資源頁目前列出的可連結教材、題卷、課程已收錄，紙本參考書目不虛構網路下載網址。
- `active` 代表列於查核時官方現行首頁，不代表每個級別／梯次當天仍接受報名。`effectiveYear` 是該筆考科表所依年度。舊版材料的年份不自動改成 115 年。
- `legacy` 為有官方停辦／整併證據的歷史鑑定，不納入 17 項現行數量。這次另列 8 個歷史代碼；尚未宣稱完整重建所有歷年改名、採認或停辦紀錄。
- 民間採認證照、職能基準名稱、徵才職類不直接當作新增的政府自辦 iPAS 鑑定；未在現行首頁找到第 18 項政府自辦現行鑑定。

## 選考、測驗方式及來源衝突

- **ANT**：初級科二含實作與紙筆說明，標 `mixed`；中級科二為紙筆申論，仍標 `written`。名字中的「實務」不等於術科。
- **PCB**：初、中級皆科一必考，科二／三擇一；初級科三含問答、單選與切片實作。
- **AIOT**：只有初級。物聯網類為科一＋二；機器聯網類為科一＋三；感知系統類為科一＋四。後兩科是術科。既有 `/aiot/` 練習站只涵蓋物聯網類兩學科。查核時官方資源頁無新版 AIoT 正式歷屆卷，不能把指引自評題或舊 IOTA 卷標為新版 AIoT 官方考古題。
- **3DP**：初級科一＋科二／三／四擇一；中級科一＋科二／三擇一。中級科一為紙筆問答，科二／三為 360 分鐘實作。初級術科在第二梯次開放，未達簡章規定人數可能取消。
- **MDMT**：官方頁摘要僅寫科二紙筆測驗，115 年簡章明列「繪製實作及紙筆測驗」，故科二標 `mixed`。
- **SPE**：初級科一＋科二／三擇一；科三實作與問答僅上半年辦理。中級兩科都是電腦選擇題。
- **PMAE**：中級有三科，第三科「常見塑膠材料檢測儀器的功能及數據判讀」是紙筆簡答。簡章收費表使用術科分類，網站 `type` 依實際答題方式記為 `written`，不因此將其轉成可自動計分的單選題。附錄有「功能及其應用」的名稱差異，本目錄以主考試科目表及 exam-info 為準。
- **EVM**：中級科目列在 exam-info 的 `method` 欄、`subject` 是空值；不能因空值漏收三科。科三含單選與另排梯次的實作，標 `mixed`。
- **CPM**：科一＋二是色彩計畫類，科一＋三是色彩管理類；可分別報考取得雙證書。科二 115 年改為電腦作答，仍是實作，不當作選擇題。
- **CV**：exam-info 高級摘要仍列「口試」，但下載的 **115.07 版最新簡章**只列三科：無形資產評價方法之整合應用、無形資產評價實作、智慧財產權法。目錄依新簡章列三科，不增列未能由新簡章確認的口試。智慧財產權法的抵免須依簡章。中級正式卷檔名有「評價概論與評價準則」，主科目表是「評價概論及評價準則」；資源保留原題卷標題。
- **NZ**：頁首仍有「中級尚未公告」舊提示，但同頁已列 115 年中級科目、場次、簡章與正式試題；以年度簡章為準。
- **AIAP**：初級兩科；中級科一必考，科二數據分析／科三機器學習擇一。既有站對應在 `levels[].existingApp`：`/junior/`、`/intermediate/`。
- **OIA**：115 年為初級兩科。既有 `/bi/` 為本站入口別名，官方代碼是 OIA。
- **品牌企劃師**：官方首頁代碼原值為小寫 `aoc`，外連全國商業總會專站；115 年只列初級，品牌管理概論與行銷企劃實務兩科均紙筆單選。樣題只標樣題，不標歷屆卷。

## 資料欄位與來源標示

- `id` 為官方代碼小寫；保留 `officialCode` 原值。`subjects[].id` 使用 `<cert>-<level>-<order>`，且在目前目錄唯一。
- `type`：`written` 包含電腦／紙筆選擇、簡答與申論；`practical` 是實作；`mixed` 是同一科含實作及其他測驗。題型是否可自動計分仍須逐卷判斷。
- `resources.kind` 保持 `guide` / `past-paper` / `syllabus` / `course`。`sourceKind` 更細分為 `official-guide` / `official-sample` / `official-past` / `official-syllabus` / `official-course`。樣題歸 `guide` 且保留 `official-sample`，不能由 `kind=guide` 推斷為教材或原創題。
- `official-course` 表示由官方頁推薦或連結的課程，不宣稱所有外站內容均由政府製作、免費或免登入。`publishedAt` 是官方資源記錄日期，並不保證等於實際考試日。
- `url` 是資源直連，`sourceUrl` 是官方將它列出的頁面。`subject` 僅在標題能明確對到唯一考科時填入；一份涵蓋多科或名稱存在差異時不猜。
- 個別資源可能包含整套試卷、複選題、申論或實作。來源解析器須保留題型與原圖，不能一律轉為四選一題目。

## 可重現的來源擷取與驗證

```sh
node scripts/fetch-ipas-catalog.mjs --output-dir /tmp/ipas-catalog-review
```

此工具只讀取公開官方頁，輸出首頁分類、逐鑑定原始 `exam`／`resource`／`attachment` 與品牌頁 HTML，保留失敗清單。2026-10-01 已實際執行完成：17 項、52 個詳細頁（48 個新版頁＋4 個品牌頁）、0 個失敗頁；另取官方首頁。

工具解析 Next.js Flight 公開資料時不執行網頁程式；特別處理長字串後 JSON 記錄未另起一行的情形，避免漏掉 EVM/NZ。網路請求保留 TLS 驗證，跟隨官方轉址。不使用登入帳號或機密。

公開 JSON 是人工核對後的目錄，擷取工具不自動覆蓋它。更新時應先比較首頁清單、級別、年度簡章及資源版本，再調整 `catalog/data/certifications.json`，避免把官方 HTML 摘要的舊文案自動發布。
