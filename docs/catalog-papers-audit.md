## 官方來源與利用範圍

1. 各鑑定新站官方學習資源頁，形式為 `https://ipd.nat.gov.tw/ipas/certification/<CODE>/learning-resources`；採官方資源 API 的 `resource.pasts` 與 `resource.samples`，不抓整本學習指引。各卷保留精確 `sourceUrl` 與 `sourceIndexUrl`，並保留原 PDF 的頁首、浮水印及署名。
2. [食品所年度考古題](https://mms.firdi.org.tw/viewdetail/context/29)：75 份 105–115 年原卷，以及同頁的疑義公告。FQA 第 76 份是 iPAS 官方資源 API 列出的初級樣題。
3. [品牌企劃師考試樣題及參考書目](https://aoc-ipas.org.tw/web/assessment/exam_questions.jsp)：115 年兩科樣題於 2026-05-18 公告、114 年兩科樣題於 2025-03-07 公告。只取 4 份官方樣題，未取參考書、民間教材或 Google Drive 輔導教材。
4. [經濟部產業發展署政府網站資料開放宣告](https://www.ida.gov.tw/ctlr?PRO=default.OpenInformation)是主站資料的再利用政策依據，允許在其涵蓋範圍內重製、改作及公開傳輸，仍須正確標示來源，並排除另有權利限制的第三方資料、商標等。這不是將所有相關外站一概宣告為公眾領域或 CC 授權。
5. FQA 食品所、AOC 全國商總為官方鑑定執行單位的外站，提供公開備考原卷。查核時未在下載 PDF 找到額外禁止利用條款，但**未找到可獨立確認涵蓋該外站全部內容的開放再利用宣告**。[AOC 安全聲明](https://aoc-ipas.org.tw/web/privacy/privacy.jsp)是個資蒐集利用告知，不能當成著作授權。這兩類資料的 `licenseUrl` 留空，並記錄此範圍；不把一般版權保留文字推論為已有個別授權，也不把未見限制推論成外站全面開放。

本次為使用者授權的備考原卷整理；保留官方出處與檔案原貌，不主張取得主辦機關背書。政府公開資料政策的適用與外站權利範圍應分開理解。

## 答案索引方法

PDF 文字層由 PyMuPDF 讀取，保留每行的頁面座標。只接受明確的答案欄字元及相鄰題號：一般左側 A–D 答案欄、與題號同一行的答案、PMAE 的數字答案欄，以及少量已視覺核對的無題號樣題。未使用 OCR 猜字，也未依題意自行補答案。

題號欄先依首題與答案欄的相對位置識別，再按頁面及垂直位置排序；不同節重新編號時，`number` 轉為全卷唯一序號，`printedNumber` 保留原题號，`sectionLabel` 保留原題型或樣題主題。答案欄框座標放在 `answerBoxes`，只作來源查核；頁圖仍保留可見答案，沒有用白塊遮掉題幹或圖。

`multiple` 依原卷的單／複選節標題及題目內「（複選）」標記設定。題組節重新依各題判定。程式將換行的「複」「選」合併核對，並防止下一節標題或下一題第一行落入上一題的判讀範圍。**未以答案字元數直接推定複選**。最終有 105 題真正複選；ABCD 也可能是全給分的單選題，兩者不能混為一談。

PDF 全頁轉圖保留公式、圖表、電路、製圖線條與原排版；此資料供「原卷研讀＋答題卡」，不是把可見答案的頁面宣稱為閉卷模考。使用者仍可開啟原 PDF 放大閱讀。完整原卷與手機頁圖的所有檔案路徑均已核對。

## 食品所疑義公告

逐梯次保留同頁公告與各科的關聯；不能因一個 HTML 段落含兩科下載連結，就把第二科套用到第一科更正。共 73 筆選擇題答案與公告對照：原卷答案保留於 `printedAnswer`，目前公告結果放在 `answer`，並附 `correctionSourceUrl`。

單選題公告同時接受多個選項時，以 `acceptedAnswers` 表示任一指定選項可接受。四個選項全給分者另標 `void`，不參與一般正確率。例：115 第一次食品品保概論第 10 題接受 C 或 D、第 5 題全給分。這與 NZ 第 29 題 ABCD 複選全部選對不同。

106 年中級統計製程品管的公告另記簡答第 5 題數字有誤、疑義成立；這則更正只記在備註，未混入第 5 題選擇題答案。
